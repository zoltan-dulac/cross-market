Firefox / Greasemonkey companion

Install the companion userscript once. On a supported marketplace, click its CrossMarket button to choose a local listing, copy fields, or fill supported visible text fields. On Google Photos, the same companion can copy the currently displayed photo into the selected CrossMarket listing.

Install Greasemonkey userscript
How to install and use it
  1. Make sure Greasemonkey is installed and enabled in Firefox.
  2. Open Install Greasemonkey userscript above and approve the script in Greasemonkey.
  3. Choose a listing here and press Use in Greasemonkey. This becomes the default listing in the userscript.
  4. Open Kijiji, Facebook Marketplace, Karrot, or Craigslist. A CrossMarket button appears at the lower-right.
  5. For Kijiji, Facebook Marketplace, and Karrot, Fill visible fields fills only recognized text fields. Category, condition, photos, and publication remain manual.
  6. Craigslist is deliberately copy-only.

The userscript connects only to http://127.0.0.1:3784. It never receives or stores your marketplace passwords, cookies, or login sessions, and it never presses a site's Post/Publish/Submit button.
